# 函数调用链视图设计

## 概述

在函数调用图模块的「模块详情」视图中新增「函数调用链」模式，与现有「热点函数图」模式并存，用户可自由切换。

## 目标

- 让用户能够选择任意函数，查看其完整的调用链关系图
- 清晰展示调用层级关系（谁调用了它，它调用了谁）
- 在边上显示调用位置和调用类型等增强信息
- 智能折叠远距离节点，避免图形过于复杂

## 用户故事

> 作为开发者，我想查看某个函数的完整调用链，了解谁调用了它以及它调用了哪些函数，以便理解代码的执行流程和依赖关系。

## 功能设计

### 1. 模式切换

在模块详情视图左侧控制面板顶部新增模式切换：

```
┌─────────────────────────┐
│ 显示设置                │
│ ┌─────────┬───────────┐ │
│ │ 热点图  │ ◉ 调用链  │ │
│ └─────────┴───────────┘ │
│ [重置]                  │
└─────────────────────────┘
```

- 默认保持「热点图」模式（现有行为）
- 切换到「调用链」模式后，右侧图形区显示选中函数的调用链

### 2. 函数选择

复用现有左侧函数列表：

- 函数列表按热度排序，支持搜索和类型过滤
- 在「调用链」模式下，点击函数列表中的函数，右侧展示该函数的完整调用链
- 选中的函数高亮显示，并在图中居中

### 3. 调用链布局

采用 Dagre 有向图布局，**从左到右**方向：

```
调用者层          选中函数          被调用者层
    ↓               ↓                  ↓
┌────────┐     ┌──────────┐      ┌────────┐
│Func A  │────→│          │─────→│Func D  │
└────────┘     │  Func C  │      └────────┘
┌────────┐     │ (选中)   │      ┌────────┐
│Func B  │────→│          │─────→│Func E  │
└────────┘     └──────────┘      └────────┘
                    │            ┌────────┐
                    └───────────→│Func F  │
                                 └────────┘
```

- 选中函数位于中心偏左
- 调用者（callers）在左侧，逐层向左展开
- 被调用者（callees）在右侧，逐层向右展开
- 同层级节点垂直对齐

### 4. 智能折叠

为避免节点过多导致图形混乱，实现智能折叠：

**折叠规则：**
- 距离选中函数超过 3 层的节点自动折叠
- 折叠节点显示为「...N 个节点」的虚拟节点
- 点击折叠节点可展开该层级

**示例：**
```
┌─────────┐     ┌──────────┐     ┌────────┐     ┌─────────┐
│...5节点 │────→│Func B    │────→│Func C  │────→│...3节点 │
│ [点击]  │     │(2层)     │     │(选中)  │     │ [点击]  │
└─────────┘     └──────────┘     └────────┘     └─────────┘
     ↑                                               ↑
   折叠                                            折叠
 (4+层)                                          (4+层)
```

### 5. 边信息增强

调用边（连线）显示增强信息：

**边上 Label：**
- 调用位置：源码行号（如 `L:42`）
- 调用类型：`direct` 或 `interface`
- 可选：调用次数（如果同一函数被多次调用）

**边样式：**
- 同模块调用：青色实线 `#00d4ff`
- 跨模块调用：橙色虚线 `#ffc145`
- 接口调用：紫色虚线 `#b08eff`

**示例：**
```
┌─────────┐  L:42,direct  ┌─────────┐
│Func A   │──────────────→│Func B   │
└─────────┘               └─────────┘

┌─────────┐  L:58,interface ┌─────────┐
│ServiceA │ ┄ ┄ ┄ ┄ ┄ ┄ ┄ ┄ →│ServiceB │
└─────────┘                  └─────────┘
```

### 6. 节点样式

复用现有函数节点样式，增强选中状态：

- 选中函数：加粗边框 + 发光效果 + "选中" 标签
- 普通节点：保持现有样式（颜色区分类型）
- 折叠节点：灰色虚线边框 + 展开图标

## 技术方案

### Store 扩展

```typescript
// functionCallStore.ts 新增状态
interface FunctionCallStore {
  // ... 现有状态

  // 视图模式
  viewMode: "heatmap" | "callchain";

  // 调用链专用状态
  callChainRootId: string | null;      // 调用链根节点（选中函数）
  collapsedNodes: Set<string>;          // 折叠的虚拟节点 ID
  callChainDepth: number;               // 当前展开深度

  // Actions
  setViewMode: (mode: "heatmap" | "callchain") => void;
  setCallChainRoot: (funcId: string | null) => void;
  toggleCollapsedNode: (nodeId: string) => void;
}
```

### 布局算法

使用 Dagre 布局库，配置：

```typescript
const layoutConfig = {
  rankdir: "LR",        // 从左到右
  nodesep: 60,          // 同层级节点间距
  ranksep: 120,         // 层级间距
  marginx: 50,
  marginy: 50,
};
```

### 数据结构

**调用链节点：**
```typescript
interface CallChainNode extends FunctionInfo {
  distance: number;      // 距离根节点的层数
  direction: "caller" | "callee" | "root";  // 方向
  isCollapsed?: boolean; // 是否为折叠节点
  collapsedCount?: number; // 折叠的节点数量
}
```

**调用链边：**
```typescript
interface CallChainEdge {
  id: string;
  source: string;
  target: string;
  sourceLine: number;    // 调用行号
  callType: "direct" | "interface";
  isCrossModule: boolean;
}
```

### 性能优化

1. **虚拟化渲染** — 大量节点时使用 ReactFlow 的虚拟化能力
2. **增量展开** — 折叠节点按需加载，避免一次性渲染过多节点
3. **缓存布局** — 布局结果缓存，避免重复计算

## 交互流程

```
1. 用户进入模块详情视图
   └→ 默认显示「热点图」模式

2. 用户切换到「调用链」模式
   └→ 如果已选中函数，直接展示其调用链
   └→ 如果未选中，提示「请从左侧列表选择函数」

3. 用户从函数列表点击某个函数
   └→ 计算该函数的完整调用链
   └→ 渲染调用链图（智能折叠远距离节点）

4. 用户点击折叠节点「...N 个节点」
   └→ 展开该层级的所有节点
   └→ 重新计算布局

5. 用户切换回「热点图」模式
   └→ 恢复热点函数图显示
```

## 边界情况

1. **无调用关系的函数** — 显示单个节点，提示「无调用关系」
2. **循环调用** — 检测并标记循环调用边，使用特殊颜色（红色）
3. **超大量节点** — 当节点数 > 200 时，默认折叠到 2 层，提示用户可展开
4. **外部函数** — 跨模块调用的外部函数显示模块名标签

## 验收标准

- [ ] 用户可切换「热点图」/「调用链」两种模式
- [ ] 在调用链模式下，点击函数列表展示完整调用链
- [ ] 调用链布局从左到右，调用者在左，被调用者在右
- [ ] 边上显示调用行号和调用类型
- [ ] 距离超过 3 层的节点自动折叠
- [ ] 点击折叠节点可展开
- [ ] 区分同模块/跨模块/接口调用的边样式
